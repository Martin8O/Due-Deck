# Warranties & Deadlines Tracker

A small personal web app for tracking important dates such as product warranties, insurance renewals, contracts, and medical appointments.  
The app runs fully in the browser and stores data locally on your device.

## Features

- Dashboard with an overview of upcoming deadlines
- List view with filters
- Calendar view
- Custom categories (electronics, insurance, contracts, etc.)
- Light / dark mode
- Keyboard shortcuts for quick actions
- Data stored in localStorage with backup/restore to JSON

## Tech Stack

- React + TypeScript
- TanStack Router / Start
- Vite
- Tailwind CSS (and component library generated by AI assistant)

## Getting Started

```bash
# install dependencies
npm install

# start dev server
npm run dev
```

Then open the URL printed in the terminal (usually `http://localhost:5173`).

## Build

```bash
npm run build
```

This creates a production build in the `dist` folder.

## Notes

This project was initially scaffolded with the help of an AI code assistant and then customized manually.





# Sledovač záruk a termínů

Malá osobní webová aplikace na sledování důležitých dat – záruk u zboží, konce pojistek, smluv nebo třeba očkování.  
Aplikace běží přímo v prohlížeči a data ukládá lokálně na tvém zařízení.

## Funkce

- Dashboard s přehledem nadcházejících termínů
- Seznam s filtry
- Kalendářový pohled
- Vlastní kategorie (elektronika, pojištění, smlouvy atd.)
- Světlý a tmavý režim
- Klávesové zkratky pro rychlou práci
- Ukládání do localStorage + záloha/obnova do JSON souboru

## Použité technologie

- React + TypeScript
- TanStack Router / Start
- Vite
- Tailwind CSS (a komponenty vygenerované AI asistentem)

## Jak spustit

```bash
# instalace závislostí
npm install

# spuštění dev serveru
npm run dev
```

Potom otevři adresu vypsanou v terminálu (obvykle `http://localhost:5173`).

## Build

```bash
npm run build
```

Produkční build se vytvoří ve složce `dist`.
